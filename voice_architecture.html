1. 🎤 Voice → Speech-to-Text (STT) Engine

நீங்கள் பேசும்போது Phone / Browser microphone உங்கள் voice-ஐ audio signal-ஆ capture செய்கிறது.

🎤 Microphone → Audio Signal → STT Engine → "WhatsApp open pannu"

Supported Models: Whisper, Google Speech Recognition, Android SpeechRecognizer, Web Speech API.

2. 🧠 AI / LLM Intent & Parameter Extraction

LLM வெறும் text-ஆ பார்க்காது; அதன் Intent (என்ன செய்ய வேண்டும்) மற்றும் Entities (எதைக் கொண்டு செய்ய வேண்டும்) ஆகியவற்றை structured format-ல் பிரித்தெடுக்கும்.

{ "intent": "SEND_MESSAGE", "platform": "WhatsApp", "contact": "Arun", "message": "நான் 10 மணிக்கு வரேன்" }
3. 🧠 Conversational Context Memory (Slot Filling)

User முழு விவரத்தையும் ஒரே வாக்கியத்தில் சொல்லாவிட்டாலும், JARVIS முந்தைய context-ஐ நினைவில் வைத்து விவரங்களைக் கேட்கும்.

  • Turn 1: User: “Arun-க்கு message அனுப்பு”
  • JARVIS State: { intent: "SEND_MESSAGE", contact: "Arun", message: null }
  • JARVIS Reply: “Sure Boss. என்ன message அனுப்பணும்?”
  • Turn 2: User: “நாளைக்கு meeting இருக்கு”
  • Execution: Merges state → Sends "நாளைக்கு meeting இருக்கு" to Arun via WhatsApp!
4. 🛠️ Tool Calling & Action Router

LLM நேரடியாக OS-ஐ இயக்காது; structured tool router மூலம் தேவையான action function-ஐத் தேர்வு செய்யும்:

open_app(app="whatsapp") make_phone_call(contact="Arun") send_whatsapp_message(contact="Arun", message="...") set_system_volume(level=50) open_camera()
5. 📱 Android & Device Assistance Control

Gemini Android implementation போன்று, JARVIS Android app permissions & system APIs மூலம் actions-ஐ execute செய்கிறது:

LLM Tool Call → Action Router → Android Intent → Target App
  • OPEN_APP: Launch intent via PackageManager (com.whatsapp)
  • CALL: Contacts lookup → Phone Dialer / WhatsApp Call
  • SMS / WhatsApp: Message compose & launch automation
6. 🗣️ Tamil + Tanglish + English Semantic Engine

JARVIS மனிதனைப் போல் semantic meaning-ஐப் பார்க்கிறது:

  • “WhatsApp open பண்ணு”
  • “WhatsApp-ah open pannu”
  • “WhatsApp திற”
  • “WhatsApp launch pannunga”

All map to single intent: OPEN_APP(WhatsApp)
